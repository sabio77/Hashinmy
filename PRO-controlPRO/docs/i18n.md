# Sistema multilenguaje textX

La semilla usa `textX` para separar textos visibles de la app y textos SEO. La base incluye español, árabe e inglés para validar idiomas LTR y RTL desde el inicio.

```text
textX/app/<idioma>.json
textX/seo/<idioma>.json
```

Cada idioma debe existir en ambas carpetas y conservar las mismas keys del idioma base `es`.

## Agregar un idioma

1. Copia `textX/app/es.json` como `textX/app/fr.json`.
2. Copia `textX/seo/es.json` como `textX/seo/fr.json`.
3. Traduce valores, no cambies keys.
4. Ejecuta:

```bash
python tools/generate-release.py --version 1.3.1 --build 2026-07-02-005
```

El script escanea automáticamente `textX/app/*.json` y `textX/seo/*.json`, crea `textX/languages.json`, actualiza `version.json` con huellas y sincroniza la lista de precache del Service Worker mediante `src/js/app-metadata.js`.

## Por qué existe `languages.json`

Un static site sin backend no puede listar carpetas del servidor de forma confiable desde el navegador. Por eso la detección automática se hace en build/release: pegar el JSON del idioma y ejecutar el script es suficiente, sin modificar código de la app. En Render, `render.yaml` ejecuta el script durante el build, por lo que solo necesitas agregar los JSON y desplegar.

## Uso en runtime

- `src/js/i18n.js` carga `textX/languages.json` con `cache: no-store`.
- Selecciona idioma por `?lang=`, preferencia guardada, `navigator.languages` y fallback.
- Actualiza `lang`, `dir`, `<title>`, meta description y nodos con `data-i18n`.
- Expone `window.AppI18n.t('ruta.key')` para módulos futuros.
